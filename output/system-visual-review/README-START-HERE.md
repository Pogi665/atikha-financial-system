# Atikha system visual consultation

Start with **system-visual-review.pdf**. Long pages are divided into overlapping, readable sections; they are never compressed into one tall strip. PDF bookmarks identify every screen. Screen numbers match all image filenames and the index.

For a browser gallery, extract this ZIP and open **index.html**. Filter by role and open a full-page PNG at its original resolution. Each state includes both a normal viewport image and a full-page image. **SCREEN-INDEX.md** and **index.json** provide route, role, state, viewport, notes and PDF page references. Copy **REVIEW-PROMPT.txt** into ChatGPT and attach the PDF; attach the ZIP too if that conversation can inspect ZIP files.

Desktop sizes: 1366x768 and eight representative 1920x1080 states. Three print-style views use print CSS media.

Captured October 23, 2026 in headless Microsoft Edge from a NEW disposable clone of the retained synthetic G7 scenario. These are actual page captures, not mockups or screenshots of the working financial database. Original pages, amounts, wrapping and layout are retained; no application DOM was restyled for capture. Static public chart/style assets were permitted; provider calls and outgoing communication stayed disabled. Synthetic example references deliberately include literal special-character test text.
