This describes the synthetic example, not an independently verified client posting. See [advance decision](decisions/004-cash-advance-accounting.md).

- The tax/funder-report note is ambiguous. It does not authorize omitting tax liabilities, selecting a tax policy or changing ledger amounts.
- Cash payments/receipts do not necessarily equal recognized expenses/income; the user selected neutral cash-movement task descriptions. Source implementation constraints are in [foundation](decisions/001-accounting-foundation.md) and [reader scopes](decisions/010-financial-reader-scopes.md).

## User product decisions and adoption concerns

The user reported difficulty finding tasks, understanding Review versus Record, locating advance actions/status and distinguishing repeated journal lines. Actual U5 observations included assistance and confusion; the later old-interface G7 was paused. None establishes that Atikha itself tested or rejected the redesigned interface.

Selected product direction: information first, explanation secondary; guided forms for tasks and familiar tables for financial review; single focused Save and close; prominent meaningful actions/state; distinct Admin/Management experiences. See [Save and close](decisions/006-save-and-close.md) and [Refined Client Experience](decisions/007-refined-client-experience.md). These are user product decisions, not new accounting policy. External software familiarity is not acceptance of this interface. Forecasting redesign remains a future user consideration; normal dashboards omit it, while retained provider services confer no accounting authority.
