## Maintenance

For a changed durable choice, mark supersession and name its replacement; preserve original date/meaning. These records are active consolidations whose Supersedes sections identify older choices/interpretations without creating files for every execution event. User product decisions and source-supported constraints are not automatically confirmed client policy.

The [exact baseline log](../history/project-decisions-legacy.md) retains chronology, temporary authorizations and test progress. [Client context](../client-context.md) owns attributed observations/unresolved policy. Dated proposal wording in old plans is not current execution status; current-state and later approved contracts establish present applicability. A document alone grants no operational authority.
